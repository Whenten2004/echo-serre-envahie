## Ouvrir le projet
Maya 2027.
Cloner avec GitHub Desktop, qui inclut Git LFS : accepter
Initialize Git LFS si la fenêtre s'affiche. En ligne de commande, faire
git lfs install AVANT le clone, sinon les assets arrivent
sous forme de pointeurs de texte et non de fichiers binaires.
